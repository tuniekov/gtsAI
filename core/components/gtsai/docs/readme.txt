gtsAI - шлюз ИИ и виджет чата для MODX.

Что умеет
  - Чат с моделью на любой странице сайта и в админке.
  - Работа с таблицами через gtsAPI: читать, а с разрешения - и править,
    с показом правки до записи и откатом после.
  - Файлы: принимает pdf, excel, csv, текст и markdown; собирает выгрузки
    (xlsx, csv, md, txt) и отдаёт ссылку на скачивание.
  - Книги Excel читает по листам: список листов, кусок листа, поиск.

С чего начать
  1. Компоненты -> ИИ (gtsAI) -> Подключения: вписать ключ провайдера.
     Ключ хранится в базе, в пакете его нет.
  2. Компоненты -> ИИ (gtsAI) -> Настройки чатов: кому чат доступен
     (группы MODX), что ему можно и какой системный промпт.
  3. Страница с чатом ставится сниппетом, пример - в настройке чата.

Доступ к базе напрямую (необязательно)
  Инструмент SQL работает от ОТДЕЛЬНОГО пользователя MySQL с правом
  SELECT. Завести его одним скриптом:
     core/components/gtsai/_install/sql_readonly.sql
  Внутри сверху три строки - имя базы, префикс таблиц и пароль. Скрипт
  сам создаёт пользователя, ограничивает его чтением вашей базы и
  прописывает логин с паролем в системные настройки.
  По умолчанию прямой SQL у чатов выключен.

Расход денег
  Каждый ответ пишется в лог с токенами и стоимостью: Компоненты ->
  ИИ (gtsAI) -> Лог. У настройки чата есть дневной лимит на пользователя.
